**RU** · [EN](README.en.md) · [中文](README.zh.md) · [Español](README.es.md) · [Français](README.fr.md)

Chrome-расширение (MV3), которое проверяет утверждения из YouTube-видео по ходу просмотра. Расширение читает субтитры прямо со страницы, сервер выделяет проверяемые утверждения с таймкодами, проверяет каждое готовыми факт-чеками людей, веб-поиском и научными статьями и показывает вердикты «правда / ложно / странно» в панели рядом с плеером. Клик по таймкоду перематывает видео к моменту, где утверждение прозвучало; у каждого вердикта источник с дословной цитатой.

«Странно» это рабочий вердикт, а не заглушка: так помечаются утверждения, по которым два прохода веб-поиска разошлись или источников не хватило. Научный слой настроен осторожно: статья влияет на вердикт, только если она прямо по теме и достаточно свежая, и никогда не выносит «ложно»: максимум понижает «правду» до «странно».

## Как это работает

```text
[каскад субтитров]     субтитры читаются со страницы; резерв на сервере: yt-dlp
        ↓
[извлечение утверждений]   проверяемые факты с таймкодами; мнения в «вне проверки»
        ↓
[проверка, три слоя параллельно]
        ├─ ClaimReview: готовые факт-чеки людей (Google Fact Check Tools)
        ├─ sonar × 2: веб-поиск; расхождение проходов → «странно»
        └─ наука: Europe PMC → OpenAlex, NLI-судейство по абстрактам
        ↓
[fusion вердикта]      конфликт «правда vs наука-опровергает» → «странно»
        ↓
[панель на YouTube]    карточки с таймкодами, источниками и весом источника
```

- **Каскад субтитров.** Октябрь 2026: YouTube закрыл прямой доступ к субтитрам, поэтому расширение пробует пути по очереди: мост из мира страницы (captionTracks живого плеера), `timed_text`, DOM-панель «Расшифровка», эндпоинт `get_transcript` с куками страницы. Если всё не сработало, сервер дотянет субтитры через yt-dlp.
- **Утверждения.** LLM размечает сегменты транскрипта: дословная цитата, категория, значимость. Мнения, прогнозы и гипербола уходят в «вне проверки», дубли схлопываются по нормализованному хэшу.
- **ClaimReview.** Если утверждение уже проверялось людьми (PolitiFact, Snopes, AFP, «Проверено.медиа»), показывается их вердикт с атрибуцией издания, LLM не вызывается. Эти карточки приезжают первыми, не дожидаясь конца экстракции.
- **sonar × 2.** Каждый факт-чек идёт двумя проходами через модель с веб-поиском; разошлись вердикты, итог «странно». Источник принимается только с дословной цитатой, выдуманные цитаты отсеиваются.
- **Научный слой.** Europe PMC (медицина/биология, без ключа) и OpenAlex (вся наука). Дешёвая модель выносит отношение науки к утверждению по топ-3 абстрактам. Наука меняет вердикт только при трёх условиях: статья прямо по теме, год не старше 2015 (или это обзор/мета-анализ), есть дословная цитата.
- **Fusion.** «Правда» против «наука-опровергает» понижается до «странно» с уверенностью «низкая» и склеенным обоснованием. В обратную сторону наука вердикт не повышает.
- **Панель.** Лента карточек с фильтром по вердиктам, карта вердиктов на таймлайне, шкала уверенности, у источников подсветка веса («наука», «официальный»).

## Возможности

- Вердикты «правда / ложно / странно» с таймкодами и шкалой уверенности; клик по таймкоду перематывает к моменту видео
- Научный слой с гвардами релевантности и свежести (Europe PMC → OpenAlex), судейство по абстрактам с обязательной цитатой
- Подсветка веса источников: «наука», «официальный» по реестру доменов с весами доверия
- Интерфейс RU/EN; язык обоснований вердиктов настраивается отдельно от языка интерфейса
- История последних 50 проверенных видео, локально в браузере
- Морф-панель: сворачивается в кружок с бейджем готовности и не занимает экран, пока идёт проверка

## Установка из исходников

Нужны Chrome/Edge 111+ и Python 3.12+. В Chrome Web Store расширения нет, только загрузка из исходников. Все проверки идут через ваш сервер на `127.0.0.1:8765`, ключи API ваши собственные.

### Сервер

```bash
cd backend
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt    # Linux/macOS: .venv/bin/pip
cd ..
cp .env.example .env
```

Впишите в `.env` ключи:

- `VFC_LLM_KEY`: ключ OpenAI-совместимого провайдера (по умолчанию bothub: deepseek извлекает утверждения и судит NLI, sonar выносит вердикты с веб-поиском на своей стороне). Обязателен.
- `VFC_SERPER_KEY`: ваш ключ поиска Serper для поискового бэкенда.
- `VFC_FACTCHECK_KEY`: ключ Google Fact Check Tools; без него слой ClaimReview просто пропускается.

Europe PMC и OpenAlex работают без ключей. Запуск сервера:

```bash
cd backend
.venv/Scripts/python -m videofactcheck.cli serve --port 8765
```

Без Chrome можно проверить одно видео из CLI: `.venv/Scripts/python -m videofactcheck.cli check "<url видео>"`.

### Расширение

1. Откройте `chrome://extensions`, включите «Режим разработчика».
2. «Загрузить распакованное расширение» → папка `extension` этого репозитория.
3. Откройте любое YouTube-видео: справа появится панель «Факт-чек». Нажмите «Проверить видео».

Субтитры приходят за ~10 секунд, утверждения за 2-4 минуты на 15-минутном видео, вердикты приезжают по мере готовности, ждать конца не обязательно: панель можно свернуть, проверка продолжится в фоне.

## Архитектура

```text
extension/                    Chrome MV3
  content.js                  панель на YouTube: карточки, таймкод-карта, морф в кружок
  page-bridge.js              скрипт в MAIN-мире: captionTracks и videoDetails живого плеера
  background.js               сервис-воркер: обмен с сервером
  options.html, account.html  настройки (язык) и история 50 видео в chrome.storage
backend/                      FastAPI + CLI
  videofactcheck/transcript.py       серверный субтитровый резерв: yt-dlp, парсер VTT с чисткой автосабов
  videofactcheck/claims.py           извлечение утверждений с таймкодами
  videofactcheck/factcheck_db.py     ClaimReview: готовые факт-чеки людей
  videofactcheck/verdict.py          sonar × 2, шкала уверенности, fusion
  videofactcheck/plausibility.py     научный слой: Europe PMC → OpenAlex, NLI с цитатой
  videofactcheck/trust.py            веса доверия доменов (whitelist/blacklist)
  videofactcheck/store.py            SQLite: прогоны, вердикты, транскрипты
  videofactcheck/server.py           HTTP API для расширения (127.0.0.1:8765)
  videofactcheck/cli.py              `serve` и `check <url>`
  tests/                             72 теста, pytest
```

Расширение отправляет серверу транскрипт, прочитанный со страницы (запросы к YouTube идут с IP пользователя, а не с IP сервера), и получает вердикты по мере их готовности.

## Статус

Пет-проект. Версия 0.9.1 (октябрь 2026), обкатан на живых видео.

Проект рос итерациями по фидбеку с реальных прогонов: каскад чтения субтитров появился, когда YouTube в октябре 2026 закрыл прямой доступ к ним; конвейер ClaimReview (готовые факт-чеки приезжают с первыми батчами экстракции) и стратификация вердиктов по таймлайну выросли из долгих прогонов 40-минутных интервью; морф-панель из жалобы «панель загораживает экран».

Ограничения: видео без субтитров отклоняются (автотранскрибация в планах), живые трансляции и Shorts не поддерживаются, за один прогон выносится до 15 вердиктов, остальное помечается «не проверено».
